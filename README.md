# Online Shopping Database System (SQL Project)

## 📌 Project Overview
The Online Shopping Database System is a SQL-based project designed to manage
customers, products, orders, payments, and inventory for an e-commerce platform.
This project demonstrates strong fundamentals of database design and SQL concepts.

---

## 🛠 Technologies Used
- MySQL
- SQL (DDL, DML)
- Triggers
- Views
- Joins and Aggregate Functions

---

---

## 🗄 Database Tables
- **Customers** – Stores customer details
- **Products** – Stores product information and stock
- **Orders** – Stores order details
- **OrderDetails** – Stores product-wise order data
- **Payments** – Stores payment information

---

## ⚙ Features
- Customer and product management
- Order and payment tracking
- Automatic stock update using triggers
- Sales analysis using SQL queries
- Views for simplified reporting
- Proper use of primary and foreign keys

---

## ▶ How to Run the Project
1. Execute `01_create_database.sql`
2. Execute `02_create_tables.sql`
3. Execute `03_insert_data.sql`
4. Execute `04_triggers.sql`
5. Execute `05_views.sql`
6. Run queries from `06_queries.sql`

---

## 📊 Sample Queries
